## 1. Векторизация vs Циклы

**Векторизация (NumPy)**
```python
# ПРАВИЛЬНО: Векторная операция
y = 2 * x + 3
```
- **Принцип:** "Заказ всех пицц одним списком"
- **Скорость:** В сотни раз быстрее циклов
- **Причина:** NumPy выполняет операции на C++ сразу со всем массивом

**Циклы (for)**
```python
# НЕПРАВИЛЬНО (для больших данных): Цикл
y = []
for val in x:
    y.append(2 * val + 3)
```
- **Принцип:** "Заказ пицц по одной"
- **Проблема:** Медленно для больших данных
- **Причина:** Каждая операция проходит через интерпретатор Python

**Вывод:** Всегда используйте готовые векторные операции NumPy/Pandas вместо циклов.

## 2. PCA (Principal Component Analysis)

**Что это?**
- Метод сжатия данных без значительной потери информации
- Находит новые оси (главные компоненты), которые:
  - PC1: Направление максимальной дисперсии
  - PC2: Перпендикулярно PC1, следующее по дисперсии

**Как работает:**
1. Находит направления максимального разброса данных
2. Поворачивает данные к новым осям
3. Позволяет отбросить оси с малым разбросом

**График "Локоть" (Elbow Plot)**
```python
# Анализ оптимального числа компонент
explained_var = np.cumsum(pca.explained_variance_ratio_)
plt.plot(range(1, n_components+1), explained_var, 'bo-')
plt.axhline(y=0.95, color='r', linestyle='--')  # 95% порог
```
- **Цель:** Найти "изгиб" графика
- **Правило:** Выбираем число компонент до резкого замедления роста

**Пример для 10 признаков:**
- 3 компоненты сохраняют ~95% информации
- Экономия памяти: ~70%
- Ускорение моделей: в ~3 раза

## 3. Когда использовать/не использовать PCA

**ИСПОЛЬЗОВАТЬ PCA, когда:**
- 50+ признаков в данных
- Нужно ускорить обучение моделей
- Требуется визуализация многомерных данных (3D→2D)
- Есть мультиколлинеарность (сильная корреляция признаков)

**НЕ ИСПОЛЬЗОВАТЬ PCA, когда:**
- Интерпретируемость признаков критически важна
- Признаки уже отобраны экспертами
- Всего 5-10 признаков
- Нужно сохранить физический смысл всех признаков

**Бизнес-пример (логистика):**
```
ДО: 100 признаков клиента
ПОСЛЕ PCA: 10 главных компонент
Результат: 
- Модель быстрее в 10 раз
- 90% информации сохранено
- Можно найти скрытые паттерны
```

## Ключевые формулы

**Нормализация (MinMax):**
```
x_norm = (x - min(x)) / (max(x) - min(x))
```

**Объяснённая дисперсия PCA:**
```
explained_variance_ratio = дисперсия_компоненты / общая_дисперсия
```

**Статистическая мощность:**
- Больше данных → меньше стандартная ошибка
- Даже маленькие эффекты становятся значимыми при N→∞
- Всегда смотреть на размер эффекта (Cohen's d), а не только p-value
